标签（空格分隔）： 管理员 academic 登录&注册

#一.用户登录接口
##**1.教师注册**
###1）功能：注册教师信息，默认编号从30000001开始
###2）端口名：
    /teacherRegister
###3）输入类型示例：
    {
	"departmentId": 31,
	"teacherPassword":"12wwwjjj2",
	"teacherName":"关羽",
	"teacherGender":1,
	"teacherIntroduction":"研究物联网技术",
	"phoneNumber":1332828292,
	"teacherEmail":"329973490@qq.com",
	"pictureId":1
    }
###4）输出类型示例：
    {
        "code":200,  //200代表成功
        "result":30000021 //新的教师号，理论从30000001开始
    }
        {
        "code":201,  //201代表失败,以下同，故省略
        "result":false
    }
##**2.学生注册**
###1）功能：注册学生信息
###2）端口号：
    /studentRegister
##3）输入类型示例
    {
    "studentId":2023,
    "specialityId":2,
    "teacherId":"30000002",
    "studentPassword":"wihd297300",
    "studentName":"王伟",
    "studentGender":1,
    "studentPhoneNumber":13966669999,
    "studentEmail":"mystudyemail@qq.com",
    "pictureId":2
    }
##4）输出类型示例
    {
    	"code": 200,
    	"result": 20230002
    }
##**3.登录**
###1）功能：根据输入的账号密码和选择的用户类型，对应查询数据库，如果类型与账号对应，账号存在，密码正确，则返回登录成功的信息，否则提示。
###2）端口名：
    /doLogin
###3)输入类型示例
    {
    "loginType":1, //0代表教务，1代表学生，2代表老师
    "id":20230002,
    "password":"12345678"
    }
###4）输出类型示例
    //正确的返回
    {
        "code":200,
        "result": 
        {
		"studentId": 0,
		"specialityId": 0,
		"teacherId": 0,
		"studentPassword": null,
		"studentName": null,
		"studentGender": 0,
		"studentPhoneNumber": 0,
		"studentEmail": null,
		"pictureId": 0
	    }
    }
    //1.用户与账号不匹配（如类型改为0）
    {
    	"code": 201,
    	"result": "用户类型与用户账号不匹配"
    }
    //2.账号不存在（如账号为20250001）
    {
    	"code": 202,
    	"result": "账号不存在"
    }
    //3.密码错误（如密码错误）
    {
    	"code": 203,
    	"result": "密码错误" 
    }

##**5.插入课程**
###1）功能：修改原先课程和插入新课程
###2）端口名：
    /insertAcademicCourse
###3)输入类型示例1：
    {
    //"courseId":0,不必填，如果填写的话表示对已有课程修改
    "departmentId":31,
    "courseName":"离散数学",
    "hour":30,
    "credit":3,
    "term":2,
    "state":0  // 0 代表此课没有开课
    }
###4）返回示例：
    {
	"code": 200,
	"result": "请求开设专业"//对于一门新课，还需要填写需要上这门课的专业
    }
##**6.插入所属关系belong**
###1）功能：插入belong
###2）端口：

###3）输入类型：

###4）输出类型：

##**7.插入教学班级class**
###1）功能：创建教学班，返回教学班信息,只需要输入课程号和人数。该过程结束后可以选择给教学班安排老师。

###3）输入类型示例：

    }

    }
